
# CodeAlpha Data Analytics Internship Project

## Project Overview
This project demonstrates three data analytics tasks using Python.

## Tasks Completed

### Task 1: Web Scraping
- Collected book titles, prices, and ratings from Books to Scrape.
- Used Requests and BeautifulSoup.
- Saved the data in `scraped_data.csv`.

### Task 2: Exploratory Data Analysis (EDA)
- Examined the dataset and its data types.
- Checked missing values and duplicate rows.
- Analysed book prices and ratings using Pandas.
- Saved the cleaned dataset as `cleaned_data.csv`.

### Task 3: Data Visualization
- Created a book price distribution histogram.
- Created an average price by rating bar chart.
- Created a top 10 expensive books chart.
- Saved the charts in the `charts` folder.

## Tools and Libraries
- Python
- VS Code
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- Seaborn

## How to Run

Install the required libraries:

```bash
python -m pip install requests beautifulsoup4 pandas matplotlib seaborn
```

Run the tasks in this order:

```bash
python task1_web_scraping.py
python task2_eda.py
python task3_visualization.py
```

## Output Files
